# Kosha offline packs (`offline` branch)

GENERATED by `tools/build_kosha_offline.py` in the ShriBuddhi repository. Do not edit by hand.

Compact gzip packs of three dictionaries (Shabdartha Kaustubha, Shabdakalpadruma,
Vachaspatyam) plus a restricted index, for the app's *offline fast mode*: the reader downloads
them once (about 33 MB), the app saves them in the browser, and lookups then run on the device
with no network. Served by GitHub Pages from this branch (root); the app reads
`offline-manifest.json` and the `pack-NN.json.gz` files it lists.

Built from the Kosha corpus commit recorded in `offline-manifest.json` (`builtFrom`).
Licences travel with the dictionaries (see their `meta` in the manifest and the `dist` branch README).
